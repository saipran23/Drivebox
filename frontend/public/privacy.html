DriveBox Privacy Policy

Last updated: 7 October 2026

DriveBox is a cloud storage management project operated by Alchuri Sai Praneeth Reddy. It lets users connect storage accounts and manage files through one interface.

Information we process

We process account information such as your name and email, authentication information, connected storage account identifiers, authorization tokens, storage quota information, file names, file identifiers, file metadata, and activity records. File contents pass through our backend when needed for uploads, downloads, previews, and enabled replication features.

How we use information

We use this information to authenticate users, connect cloud accounts, display storage usage, organize and transfer files, provide sharing and delivery rooms, monitor provider health, and troubleshoot the service. Enabled replication or failover features may transfer files between your connected providers.

Google Drive access

With your permission, DriveBox accesses Google account information and Google Drive to provide its file management features. The current integration requests broad Drive permission, which can authorize access beyond files created by DriveBox. DriveBox uses this access for its storage functionality.

DriveBox's use and transfer of information received from Google APIs will comply with the Google API Services User Data Policy , including its Limited Use requirements. Google user data is not sold, used for advertising, or used to train general-purpose AI models.

Storage and service providers

Files are stored in connected cloud storage services. Account records, file metadata, and encrypted provider tokens are stored in our database. DriveBox uses Vercel for frontend hosting, Render for backend hosting, and Aiven for its database. These services process data needed to operate the application.

Sharing

Information is transferred to connected storage providers as needed to carry out your actions and enabled features. If you create a public file link, anyone with that link may access the shared content while the link remains active. Delivery-room uploads are available to the room owner.

Retention and deletion

Account records and associated metadata are retained to provide the service until removed or a deletion request is processed. To request deletion of your DriveBox account and associated application data, contact the email below. Disconnecting a provider or revoking access does not by itself delete files already stored with that provider or all previously stored application records.

You can revoke Google's authorization through Google Account connections . You can also manage or delete files directly with your storage provider. Provider backups and logs follow the respective provider's retention practices.

Security

The deployed service uses HTTPS and encrypts stored provider tokens. No online service can guarantee absolute security.

Contact and changes

For privacy questions or deletion requests, contact YOUR_CONTACT_EMAIL. Updates to this policy will be published on this page with a revised date.
